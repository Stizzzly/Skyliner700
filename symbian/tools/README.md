# Диагностические утилиты Nokia 6600

Отдельные приложения для исследования телефона. В игру не входят и для
полёта не нужны. В каждом каталоге есть исходники, собственные сборка и README.

| Утилита | Назначение |
|---|---|
| [DeviceInventory](device-inventory/README.md) | Список устройств, каналов и файлов драйверов |
| [KeyHookProbe](keyhook-probe/README.md) | Эксперимент с EKA1 event hook; на телефоне зафиксирован KERN-EXEC 12 |
| [SystemDump](system-dump/README.md) | Чтение файлов диска Z: и передача по Bluetooth; это не сырой ROM-дамп |
| [DumpCleanup](dump-cleanup/README.md) | Удаление собственных списков и отчётов SystemDump |

В `dist/` каждой утилиты оставлен последний установщик. Старые версии
сохраняются в истории Git. Подтверждённые результаты и непроверенные части
описаны в README соответствующей утилиты.
