# DumpCleanup 0.1.0 — убрать метаданные SystemDump

Закройте SystemDump. Установите DumpCleanup.sis и откройте DumpCleanup.
Нажмите 5 или левую софт-клавишу Clean. Deleted — число удалённых файлов;
failed/error — ошибки (например, файл ещё открыт SystemDump); Kept — чужие
имена/папки, которые утилита сохранила. После завершения можно удалить
SystemDump и DumpCleanup через диспетчер приложений.

Удаляются только файлы в C:\SystemDump\ с точным шаблоном
N6600_YYYYMMDD_HHMMSS_manifest.tsv, _manifest.tsv.part или _transfer.log.
Никакого рекурсивного удаления, очистки диска или других масок нет.
Если папка стала пустой, удаляется сама папка. Иные файлы, в том числе .bin/.zip,
сохраняются. Z:, содержимое второго телефона и Skyliner700 не затрагиваются.
Приложение не создаёт логи и архивы. Установка самой утилиты удаляется штатным
диспетчером приложений, а не самостоятельным удалением системных каталогов.
