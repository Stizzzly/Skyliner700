# Skyliner 700 — Xbox 360 Edition

[English version](README.md)

Эта ветка содержит нативный порт **Skyliner 700** для **Xbox 360** — небольшого авиасимулятора на C. Это отдельная от Windows-релиза (`main`) ветка кодовой базы: результатом сборки является `.xex` для Xbox 360.

## Возможности

- Упрощённая физика: взлёт, сваливание, развороты с креном, посадка и контакт с terrain
- Управление под Xbox 360, главное меню, пауза, HUD, телеметрия, автотест полёта и свободная камера
- Процедурная карта с холмами, ВПП, рулёжной площадкой и low-poly ангарами
- Runtime-текстуры DDS: DXT1 для земли, DXT5 для облаков и ливрея самолёта 1024×1024
- Sky dome, движущиеся облака, туман, анизотропная фильтрация и рендер в 720p

## Преимущества Xbox 360-версии

Помимо общей игровой и физической логики, у порта есть отдельный рендерер и путь вывода для Xbox 360:

- Нативные 1280×720 с 4× MSAA: используются 10 МБ eDRAM Xenos, explicit predicated tiling и resolve
- Полноценное управление и навигация по меню с геймпада
- DDS-ассеты и платформенная фильтрация для более чётких текстур земли и самолёта
- Прямое использование GPU и архитектуры памяти Xbox 360, а не запуск Windows-версии через слой совместимости

## Управление

| Управление | Действие |
| --- | --- |
| Левый стик | Тангаж и крен |
| Правый стик | Обзор в свободной камере |
| Левый / правый триггер | Уменьшить / увеличить тягу |
| Левый / правый бампер | Рыскание |
| `Back` | Камера третьего лица / свободная камера |
| `Крестовина вниз` | Включить / выключить подробную телеметрию |
| Нажать оба стика | Запустить автоматический тестовый полёт |
| `Start` | Открыть или закрыть меню паузы |
| `Крестовина вверх` / `Крестовина вниз` или левый стик | Навигация по меню |
| `A` | Подтвердить действие меню |

## Структура проекта

```
src/common/        Общая C-логика: физика, сценарий полёта, terrain, данные самолёта
src/win32/         Windows-код, сохранённый для совместного исходного кода; Xbox-проект его не собирает
platforms/xbox360/ Решение Visual Studio 2010 и платформенный bootstrap Xbox 360
assets/source/     Редактируемые исходники графики
assets/xbox/       Runtime-ассеты DDS для Xbox
tests/             Headless-проверки модели полёта
```

Откройте решение `platforms/xbox360/Skyliner700Xbox360/Skyliner700xbox360.sln`.

## Сборка и запуск

Для сборки необходим **лицензионный Microsoft Xbox 360 XDK** с поддерживаемой им средой Visual Studio 2010. Заголовки, библиотеки, инструменты, примеры и файлы развёртывания XDK являются проприетарными и намеренно не включены в этот репозиторий.

Поддерживаемая целевая платформа для запуска — официальный devkit Xbox 360. Соберите конфигурацию `Release | Xbox 360` в Visual Studio и отправьте созданный `.xex` вместе с папкой `assets` на devkit.

Игра может запуститься на модифицированной retail-консоли с JTAG/RGH/BadUpdate/BadAvatar, однако такой вариант не проверялся и не поддерживается. Проект не содержит инструкций, файлов или гарантий, связанных с обходом защиты платформы: используйте легальное оборудование и ПО для разработки.
